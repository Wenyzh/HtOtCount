# HtOtCount
Automatic count method in count9
Code Usage Instructions

Overview
This repository contains MATLAB code for analyzing head swings and omega turn in behavioral experiments. The main script is designed to process and analyze relevant data.

Requirements
MATLAB (version R2016a or later recommended)

How to Run the Code
Clone or download this repository to your local machine.
Open MATLAB and navigate to the repository folder.
Run headThrashesCount4
This will start the analysis process.
